# ghost2champion
This repository contains the analysis notebook for a work-based MSc service evaluation of engagement with the Sorted: Mental Health app.

## Project overview

The evaluation examines engagement patterns among users of the Sorted app, including ghost users, partial engagers, listeners and sustained engagers. It also explores how engagement varies by route of access and examines exploratory clinical outcome patterns using GAD-7 and PHQ-8 change scores.

## Data availability

The raw datasets are not included in this repository due to confidentiality and data governance restrictions. The analysis was conducted using anonymised routine app data provided by Positive Rewards Ltd.

## Repository contents

- `app_engagement_analysis.ipynb`: main analysis notebook
- `requirements.txt`: Python packages used
- `data/README.md`: data access note
- `outputs/figures/`: exported figures

## How to run

1. Install the packages listed in `requirements.txt`.
2. Place the required raw data files in the `data/` folder.
3. Run the notebook from top to bottom.

## Author contribution

The analysis, code, interpretation and dissertation write-up were completed by the author as part of a work-based service evaluation.
